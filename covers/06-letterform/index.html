Vizuara Books — a cover system proposal

One book, one character. Every Vizuara title is assigned a single character — an operator, a Greek letter, a token — taken from the working heart of its subject, and set at monumental size on one shared line that runs across the whole library.

The character is the image; the title hangs beneath it like the caption on a type specimen, and a one-line codepoint says exactly which character you are looking at. Maths is set in the face of the equation, code in the face of the terminal, and the level of a book is simply how much ink is on its cover. Fifty books become a character set — a shelf you can read.

  1. The character. One per book, chosen from its subject — never a picture of “AI”. It may be cropped by any edge, never distorted, and it is set in the face it lives in: Libertinus for maths, Chivo Mono for code.
  2. The line. Every character rests on the same rule, 560 px (5.83 in) from the head. Nothing crosses it; everything below it is text.
  3. The codepoint. A caption names the character exactly — U+2202 PARTIAL DIFFERENTIAL — so the library doubles as a character set (see the back cover).
  4. Ink density = level. Bare paper, a flood of ultramarine, or black. It reads at 180 px and survives greyscale.
  5. Signature, not shout. The imprint is Vizuara’s own character, an italic v, beside a 17 px wordmark. Forthcoming titles are hatched, not yet inked; sub-series carry a Roman numeral.
