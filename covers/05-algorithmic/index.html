Vizuara Books — cover system proposal 05 — algorithmic

Figure 0Every cover is one run of the book’s own algorithm.

A technical book’s cover should be evidence, not decoration. In Figure 0 each plate is computed in the page, at print time, by the subject of the book itself: gradient descent draws the maths book, a network trained right here draws Neural Networks, a pipeline schedule draws 5D Parallelism, an agent session run through three compaction policies draws Pi vs Hermes vs Codex.

The caption is always “Fig. 0” and says exactly what ran, with every number read back from the run — so the cover is the book’s first worked example. Everything around it stays quiet: one serif for the title, one mono for data, three grounds for three levels, and one signal colour that always marks the answer.

Level is depth

The same three colours, rotated: the deeper the book, the darker the plate. The accent is whichever colour the ground is not, and it only ever marks the result — the minimum, the boundary, the shock. Three squares top-left repeat the level for greyscale print.

The core six

Plates are SVG, generated deterministically from a seed hashed from each slug — reload and you get the same cover; change the algorithm and the cover changes with it.

Range

A beginner title, an advanced one with a long parenthetical, and a forthcoming book that has a subtitle but no capsule count yet.

Sub-series — Charlie and the Intelligence Factory

The four rooms trade the full-bleed field for a square “room” plate and an italic lead-in; the room number rides the top line. Each room computes its own subject.
